# Game Library

A Steam Deck–style catalog for my games on PC, PS5, Switch and Switch 2.

- Track each game as **Owned**, **Started**, **Finished** (credits rolled) or **Completed** (100%)
- Filter by platform and status, search, sort
- Covers found automatically: Steam portrait art when the game is on Steam (via Wikidata), otherwise the Wikipedia box art. Pick another or upload your own.
- Syncs across devices through a private GitHub Gist (needs a token with only the `gist` scope, pasted once per device)
- Export / import a JSON backup
- Installable: open the site in Chrome → menu → *Add to Home screen*

Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
